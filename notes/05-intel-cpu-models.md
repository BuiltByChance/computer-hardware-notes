# P5 · 4.CPU厂商、IntelCPU实战分析｜拆读酷睿型号、核对后缀与跨代性能

**以 `Core i9-12900K` 为例**，`Core i9` 是酷睿家族中的档位，`12` 表示第 12 代，`900` 是该系列的型号编号，`K` 表示解锁倍频。i3、i5、i7、i9 适合同代、同平台内初筛。跨代时，旧 i7 和新 i5 谁更快要看具体任务。Core Ultra 采用另一套编号，例如 `Core Ultra 7 165H` 属于系列 1。[英特尔型号命名指南](https://www.intel.cn/content/www/cn/zh/processors/processor-numbers.html)

## 后缀会影响什么

| 后缀 | 选择时的含义 |
| --- | --- |
| K、F、KF | K 可在支持的平台上调倍频。F 没有可用核显，需要独立显卡才能显示画面。KF 兼有两项特征。 |
| H、HK、HQ | H 用于高性能移动处理器。HK 还解锁倍频，旧款 HQ 表示高性能移动四核。 |
| U、Y、T | U 侧重移动能效，Y 用于极低功耗移动产品，T 用于功耗优化的桌面产品。笔记本续航还取决于电池、屏幕和实际负载。 |
| G1–G7 | 表示相应型号的核显级别，如 `i5-1155G7` 的 G7。 |
| S、X、XE | i9-12900KS 中的 S 表示特别版。旧款 X、XE 用于解锁倍频的高端产品。 |

不同家族、年代采用的后缀不同，遇到陌生字母应查对应产品线。[英特尔后缀表](https://www.intel.cn/content/www/cn/zh/support/articles/000058567/processors/intel-core-processors.html)

## 比较两款处理器

1. **抄全型号。** 在笔记本商品页的「规格与包装 → 处理器 → CPU 型号」确认具体配置。“第 11 代 i5”可以对应多款处理器，`i5-1155G7` 才能定位到一款。
2. **查官方规格。** 在英特尔产品规格库（ARK）按完整型号搜索，选「添加到比较」，并排看发布日期、核心与线程、功耗和核显。例如 i9-12900K 的发布日期 `Q4'21` 表示 2021 年第四季度。[ARK 比较步骤](https://www.intel.cn/content/www/cn/zh/support/articles/000027710/processors.html)
3. **按用途验证。** 比较 `i7-7700` 和 `i5-12600` 时，玩游戏看相同显卡、画质下的帧率，做视频看相同素材和设置下的编码用时。比较 Intel 与 AMD 也可用同样的方法。若选笔记本，还要核对整机的显卡、内存和散热，再判断价差是否值得。

摩尔定律描述集成电路上晶体管数量约每两年翻一番的历史趋势。要估算具体软件加速多少，仍需查看实测结果。[英特尔对摩尔定律的说明](https://www.intel.com/content/www/us/en/newsroom/resources/moores-law.html)
