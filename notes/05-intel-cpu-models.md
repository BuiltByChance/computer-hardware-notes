# P5 · 4.CPU厂商、IntelCPU实战分析｜拆读酷睿型号、核对后缀与跨代性能

看到“酷睿 i7”时，先找完整型号。它能告诉你处理器属于哪一代、面向台式机还是移动设备，以及是否有核显等关键信息。要回答“哪台运行我的软件更快”，还要找对应任务的测试。

## 用 i9-12900K 读懂传统酷睿型号（17:16 起）

| 名称部分 | 怎么用 |
| --- | --- |
| `Core i9` | 酷睿系列中的产品档位。录课时常见的档位有 i3、i5、i7、i9，适合在同代、同类产品中做初筛。 |
| `12` | 第 12 代。旧款 `i9-9900K` 的第一个 `9` 表示第 9 代。要知道型号具体何时推出，查厂商的“发布日期”。 |
| `900` | 这款产品在该代系列内的 SKU 编号。保留完整编号，不宜取其中一位当成通用性能分数。 |
| `K` | 这款桌面处理器已解锁倍频。是否支持调节，还要看搭配的平台。 |

课中用文档办公举例说明 i3 的定位，用简单剪辑、编程和游戏说明 i5，再用较重的游戏和工程项目说明 i7、i9。这些用途适合初筛，同一款软件处理小项目和大项目时，需求也会不同。

**新型号要换读法。** 视频以 2022 年在售产品为例。现在的 Core 和 Core Ultra 有各自的编号规则，例如 `Core Ultra 7 165H` 中，`7` 是档位，`165H` 属于系列 1。遇到不同格式时，从官方名称指南找到对应产品家族再拆读。[英特尔处理器名称与编号](https://www.intel.cn/content/www/cn/zh/processors/processor-numbers.html)

## 后缀会怎样影响装机或选笔记本（30:20 起）

| 后缀 | 查看商品时的实际含义 |
| --- | --- |
| K、F、KF | K 表示解锁倍频。F 表示处理器没有可用的集成显卡，普通桌面机需要独立显卡提供画面。KF 同时具有这两个特征。 |
| H、HK、HQ | H 面向高性能移动设备，HK 还支持解锁倍频，旧款 HQ 表示高性能移动四核。要判断 CPU 能否拆换，另查封装及整机维修资料。 |
| U、Y、T | U 面向高能效移动设备，Y 面向极低功耗移动设备，T 用于功耗优化的桌面型号。笔记本续航还取决于电池、屏幕和负载。 |
| G1–G7 | 在采用这套命名的型号中指集成显卡级别。例如 `i5-1155G7` 的 G7 描述图形配置。判断续航需另查整机数据。 |
| S、X、XE | S 表示特别版。旧产品中的 X、XE 指未锁频的高端产品线。跨代选择仍要核对具体型号。 |

不同年代用到的后缀有变化。查到少见字母时，可直接对照英特尔的后缀表及该型号的“处理器显卡”字段。[英特尔后缀释义](https://www.intel.cn/content/www/cn/zh/support/articles/000058567/processors/intel-core-processors.html)

## 比较两款 CPU 的步骤（19:35、27:49、43:03 起）

1. **抄全型号。** 商品标题只写“第 11 代 i5”时，按片中京东入口打开 **规格与包装 → 处理器 → CPU 型号**。讲师由此读到华为笔记本的 `i5-1155G7`。切换整机配置后，再核对一次型号。
2. **在英特尔产品规格页（ARK）核对。** 看型号后缀、发布日期、核心与线程、功耗和处理器显卡。片中 `i9-12900K` 的 `Q4'21` 指 2021 年第四季度发布。搜索旧款时实际点开的是 `i9-9900KF`（2019 年第一季度），少一个 F 的 `i9-9900K` 则是 2018 年第四季度。也可把两款分别“添加到比较”，并排查看规格。[ARK 比较操作说明](https://www.intel.cn/content/www/cn/zh/support/articles/000027710/processors.html) · [第 9 代酷睿 i9 官方清单](https://www.intel.cn/content/www/cn/zh/ark/products/series/186673/9th-generation-intel-core-i9-processors.html)
3. **跨代时看实际任务。** 片中搜索用的板书组合未命中，最后打开的网页对比的是 `i7-7700` 与 `i5-12600`。先核对结果页上的两个完整型号，再看指标和样本条件。网站综合评分、同一游戏同一设置下的帧率、编码同一段视频的用时，回答的是三个不同的问题。
4. **把标价与整机配置一起看。** 片尾的惠普暗影精灵 8 可在 `i7-12700H` 与 `i5-12500H` 配置间切换，机械革命旷世页面也展示了 `i9-12900H` 和 `i7-12700H`。两台笔记本的显卡、内存或散热也可能不同，整机价差不能全算在 CPU 上。

比较 AMD 和 Intel 同样要先限定时期、预算和用途。摩尔定律的经典表述是集成电路的晶体管数量约每两年翻一番。要估计某款游戏或软件的性能差距，需要该工作负载的测试数据。[英特尔对摩尔定律的说明](https://www.intel.com/content/www/us/en/newsroom/resources/moores-law.html)
