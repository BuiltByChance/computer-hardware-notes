# P9 · 8.内存和内存条的用途｜观察 RAM 占用、读懂内存套装容量

运行内存（RAM）用来存放 CPU 正在处理的程序和数据。浏览器多开几个标签页、开发工具加载一个项目，即使应用数量没变，需要的内存也可能增加。判断容量够不够，先看自己的日常工作会用掉多少。

## 用任务管理器做一次前后对照（05:40–08:08）

1. **打开任务管理器。** 右键 Windows「开始」按钮，选「任务管理器」，也可以按 `Ctrl + Shift + Esc`。如果像视频里一样只看到简短的应用列表，点左下角「详细信息」。
2. **看一个应用。** 在「进程」页找「内存」列。选一个常用程序，记录打开前后的数值，再加载平时会用的文件或项目。课中 Chrome 已在运行，读数约为 680 MB。随后启动 Visual Studio 2022，其进程组占用从约 380 MB 上升，点开最近的解决方案后又升至约 770 MB。具体数值随负载变化。
3. **看整台电脑。** 切到「性能 → 内存」，读总容量、正在使用的容量和可用容量。课中虚拟机一度显示 **5.2 / 8.0 GB（65%）**，即总共 8.0 GB，已用 5.2 GB，可用约 2.8 GB。这里 5.2 的单位是 GB。
4. **验证关闭后的变化。** 保存工作，正常关闭刚才的应用，再看同一张曲线。讲师从任务栏关闭 Visual Studio，占用从约 64% 降至 **4.1 / 8.0 GB（51%）**，可用约 3.9 GB。这里的 51% 是关闭后仍在使用的比例。[微软的任务管理器操作说明](https://support.microsoft.com/zh-cn/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)

内存容量影响能同时留在 RAM 里的工作量，能开几个应用取决于每个应用装入了什么。实际判断时，看典型负载下可用内存是否持续紧张、切换应用是否变慢。Windows 还可以用分页文件缓解物理内存压力，因此单看“已用 90%”无法断定下一个程序会启动失败。[微软的分页文件说明](https://learn.microsoft.com/zh-cn/troubleshoot/windows-client/performance/introduction-to-the-page-file)

## 读懂两种容量写法（04:10–04:54、10:50–13:22）

| 商品上的写法 | 如何解读 |
| --- | --- |
| 手机 `8 GB + 256 GB` | 前一项是运行内存，后一项是保存应用、照片和文件的存储容量。换成 `8 GB + 128 GB`，运行内存仍是 8 GB。[Redmi K50 Pro 官方规格](https://www.mi.com/redmik50pro/specs) |
| 内存条套装 `16 GB（8 GB × 2）` | 两根，每根 8 GB，套装共 16 GB。装齐这套需要两个兼容插槽。课中另一档 `32 GB（16 GB × 2）` 同样是两根，每根容量翻倍。[海盗船 VENGEANCE LPX 16 GB 套装规格](https://www.corsair.com/cn/zh/p/memory/cmk16gx4m2d3200c16/vengeancea-lpx-16gb-2-x-8gb-ddr4-dram-3200mhz-c16-memory-kit-black-cmk16gx4m2d3200c16) |

## 升级前核对插槽和兼容性（02:24–03:43、12:10–13:56）

- **先查主板或笔记本的具体型号。** 在厂商规格或维修手册里确认内存是板载还是可更换、有几个插槽、已占用几个、支持哪代 DDR 和多大容量。课中的旧主板照片标有两条 DDR2 DIMM 插槽，可以通过长槽和端部卡扣辨认位置。
- **再看商品对应的平台。** 普通台式机常用 DIMM，带可更换内存的笔记本常用较短的 SO-DIMM。有些笔记本使用焊接内存。即使容量都写 16 GB，也要逐项核对外形、代际和容量上限。[金士顿笔记本内存升级指南](https://www.kingston.com/cn/blog/gaming/how-to-upgrade-laptop-ram)
- **算清升级后的总量。** 若原来的两根 4 GB 已占满两个插槽，把两根都换成 8 GB 后，总量是 16 GB。讲师在 2022 年提出“16 GB 起步”，选容量时更有参考价值的是自己同时运行哪些程序，以及上述前后对照的结果。
