# P9 · 8.内存和内存条的用途｜观察 RAM 占用、读懂内存套装容量

RAM 临时保存程序正在处理的数据。一个浏览器开更多标签页、一个开发工具载入更大的工程，都可能增加占用。

## 测一次日常负载

1. 按 `Ctrl + Shift + Esc` 打开任务管理器。若只显示应用列表，先点「详细信息」。在「进程 → 内存」看单个应用或进程组。示例中 Visual Studio 2022 从启动到打开解决方案，占用约从 **380 MB 升至 770 MB**。
2. 在「性能 → 内存」看整机的「使用中」和「可用」。示例虚拟机有 8.0 GB RAM，整机一度用到 **5.2 GB（65%）**。保存并关闭 Visual Studio 后降到 **4.1 GB（51%）**。
3. 用自己经常同时运行的应用复查。若可用容量持续很低，切换应用也变慢，再考虑扩容。Windows 会使用分页文件，单个占用百分比无法判定下一程序能否启动。[微软分页文件说明](https://learn.microsoft.com/zh-cn/troubleshoot/windows-client/performance/introduction-to-the-page-file)

## 看容量与插槽

| 标注或条件 | 怎么算、怎么选 |
| --- | --- |
| 手机「8 GB + 256 GB」 | 8 GB 是运行内存，256 GB 是保存应用和文件的存储容量。 |
| 内存套装「16 GB（8 GB × 2）」 | 每根 8 GB，共 16 GB，需要两个兼容插槽。双槽都装着 4 GB 时，换成两根 8 GB，升级后共 16 GB。 |
| 台式机或笔记本升级 | 按整机或主板型号查手册，确认 DDR 代际、插槽数、已占用的槽和容量上限。台式机常用 DIMM，笔记本可更换的条常用较短的 SO-DIMM。板载内存要另查是否留有扩展槽。[金士顿笔记本内存升级指南](https://www.kingston.com/cn/blog/gaming/how-to-upgrade-laptop-ram) |
