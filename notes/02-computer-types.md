# P2 · 1.计算机分类｜台式机、笔记本、工作站与服务器

台式机、笔记本按设备形态区分，工作站、服务器按用途区分。同一台机器可以同时属于两类，例如供设计师随身制图的移动工作站。

| 类别 | 适用场景与选用依据 |
| --- | --- |
| 台式机 | 固定工位使用。机箱内核对主板、CPU、内存、硬盘、电源和所需的独立显卡，外设另列显示器、键盘和鼠标。 |
| 笔记本 | 屏幕、键盘和电池集成在一起。经常携带、主要写文档时，看重量和续航。玩游戏、剪视频或做设计时，按具体软件和项目比较性能。 |
| 工作站 | 服务于制图、设计、影视制作等专业任务。先确认软件更依赖 CPU、内存还是显卡，再选塔式或移动机型。 |
| 服务器 | 通过网络向其他设备提供服务。例如文件服务器供多台电脑读写共享文件，账户服务处理登录和查询。局域网内也能提供这些服务。 |

**读配置单。** 戴尔 T5820 的一个配置列出至强 W-2245、64 GB 内存和 RTX 4000 8 GB。64 GB 是系统内存，8 GB 是显卡自带的显存。商品页能切换配置，要以当前选项为准。
