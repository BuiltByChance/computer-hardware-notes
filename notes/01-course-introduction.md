# P1 · 0.开骂开端｜从使用需求出发选电脑

挑笔记本或配台式机时，先说清楚自己要用电脑做什么，再判断硬件参数对这个用途有什么影响。

| 回看位置 | 值得记住的问题 |
| --- | --- |
| 00:20 起 · 明确用途 | 我想玩哪款游戏、用哪款软件？这台电脑能运行它吗？运行时会不会卡？“能运行”和“用起来流畅”是两个问题。 |
| 00:45 起 · 理解名词 | CPU（中央处理器）承担运算和控制。记住这个定义后，还要能回答选机时的问题：这颗 CPU 能否满足我的具体用途？本节用定义举例，型号比较留待后续。 |
| 02:17 起 · 阅读商品参数 | 看硬件商品页时，依次问自己：这个参数表示什么？它对我要做的事有什么影响？这个优点值得我为它选这件硬件吗？ |
| 02:43 起 · 作出选择 | 配台式机要回答“哪些硬件搭在一起”，选笔记本要回答“哪台整机能满足我的用途”。这是后续课程要解决的两类问题。 |
