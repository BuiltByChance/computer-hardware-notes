# P1 · 0.开骂开端｜从使用需求出发选电脑

选电脑前，把“够用”写成能验证的条件。例如玩游戏记下游戏名、分辨率、画质和目标帧率。剪视频记下常用软件、素材分辨率和能接受的导出时间。

| 选什么 | 怎样判断 |
| --- | --- |
| CPU 和显卡 | 游戏先看目标设置下的实测帧率。剪视频若最在意导出速度，就比较不同机器导出同一项目所需的时间。 |
| 组装台式机 | 到主板的 CPU 支持列表查处理器完整型号和所需 BIOS，再查内存槽用 DDR4 还是 DDR5。已有的内存能否沿用，取决于具体板型。[核对 CPU 与主板](23-cpu-motherboard-compatibility.md) |
| 笔记本 | 抄下具体机型编号、GPU 和显存容量。同一系列里，一款可能配 8 GB 显存，另一款只有 4 GB。用选中的配置对照软件要求。[游戏本配置实例](21-gaming-laptops-and-system-requirements.md) |
