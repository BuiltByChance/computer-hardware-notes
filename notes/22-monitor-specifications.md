# P22 · 21.显示器重要的指标｜核对屏幕像素、刷新率与 HDR，判断游戏负载

## 在商品页查到确切的屏幕规格

1. **选中具体配置。** 同系列笔记本可以跨年份、配不同屏幕。课堂在联想商品页的「选择处理器或显卡」一栏切换配置。每次切换后，重新核对商品标题中的机型、CPU 和显卡。
2. **找到横向和纵向像素数。** 课堂京东页面的入口是「规格与包装 → 显示器 → 屏幕分辨率」。第 11 代酷睿拯救者 Y7000P 的标题只标了 165 Hz，规格表才给出 **15.6 英寸、16:9、1920×1080**（10:10–10:15）。标题省略分辨率时，凭完整型号到厂商规格页查。
3. **也看「商品介绍」顶部的参数摘要。** AOC 24G2 的标题写着 144 Hz，01:45 的摘要里还列了 **1920×1080**，讲师当时略过了这一行。厂商规格进一步列明，用 HDMI 或 DisplayPort 可同时达到 **1920×1080、144 Hz**。[AOC 24G2 规格](https://www.aocmonitor.com.cn/product-1768.html)

## 把分辨率、刷新率和游戏帧率对起来

- **分辨率决定每帧的像素数。** 1920×1080 约为 207 万像素，2560×1440 约为 369 万，3840×2160 约为 829 万。在同一游戏、相同画质下，以原生 4K 渲染一帧的像素数是 1080p 的 4 倍，GPU 通常要做更多工作，渲染缓冲也会占用更多显存。帧率的变化幅度要看具体游戏。
- **刷新率看屏幕，帧率看游戏。** 144 Hz 表示屏幕每秒可刷新 144 次。要让游戏中的快速移动更连贯，电脑还需要及时算出足够多的新画面。比较游戏本时，先定目标游戏、分辨率、画质和期望帧率，再找相同条件下的实测。[Intel 刷新率与游戏帧率说明](https://www.intel.com/content/www/us/en/gaming/resources/highest-refresh-rate-gaming.html)
- **同一显卡可以配不同分辨率的屏幕。** 课堂的第 11 代酷睿 Y7000P（RTX 3050 Ti）实查为 1080p。切到 2022 款后，i7-12700H／RTX 3050 Ti 与 i5-12500H／RTX 3050 两款都标了 2.5K。讲师没有测这几款的游戏帧率。

## 拆读电竞显示器标题里的其余指标

课堂中的三星玄龙骑士 **C27G55TQWC** 把多项规格写在同一行。厂商逐项列出了 27 英寸、2560×1440、最高 144 Hz、1000R、1 ms MPRT、FreeSync Premium 和 HDR10。[三星同型号规格及测试条件](https://www.samsung.com/tw/monitors/gaming/wqhd-gaming-monitor-g5-27-inch-lc27g55tqwcxzw/)

| 标注 | 复习时怎么读 |
| --- | --- |
| 1000R | 曲面对应半径 1000 毫米的圆弧。比较曲面屏时，半径越小，弯曲越明显。 |
| 1 ms MPRT | 动态画面响应时间，用于描述运动模糊。三星这个数值来自 Extreme 模式下的厂测。从按键到画面变化的整机延迟要另测。 |
| FreeSync Premium | 在支持的刷新率范围内，让屏幕刷新跟随显卡出帧，减少画面撕裂、卡顿。低蓝光是规格表里的另一项功能。 |
| HDR10 | 表示支持 HDR10 信号。评估亮部与暗部能否同时保留细节，还要看屏幕的实际亮度、黑位等表现。AOC 24G2 的「HDR Mode」则是通过调节颜色与对比度模拟效果。 |
| 100% sRGB | 课堂联想商品标题中的色域标注，描述屏幕能覆盖的颜色范围。若用于修图或调色，还要另外核对色准。 |

讲师找到的灰阶图和多张曝光合成的风景照可用来理解亮暗细节。要检验一台显示器的 HDR 表现，需要使用 HDR 内容并在该屏幕上开启 HDR。比较标称性能时可核对 VESA DisplayHDR 认证等级。[VESA 对 HDR10 与 DisplayHDR 的说明](https://displayhdr.org/not-all-hdr-is-created-equal/)
