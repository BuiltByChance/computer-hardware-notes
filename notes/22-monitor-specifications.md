# P22 · 21.显示器重要的指标｜核对屏幕像素、刷新率与 HDR，判断游戏负载

## 分辨率和刷新率要分开读

先选定完整机型，再在商品页的“规格与包装 → 显示器”或厂商规格表里找**横向 × 纵向像素数**。联想把两块 165 Hz 屏都称作“2.5K”，Y9000K（i7-11800H、RTX 3060）是 2560×1600，Y7000P 2022（i5-12500H、RTX 3050）是 2560×1440。在相同缩放比例下，前者可多显示 160 行像素的内容，按原生分辨率渲染时每帧也要多算 409,600 个像素。[Y9000K 规格](https://item.lenovo.com.cn/product/1021207.html) · [Y7000P 规格](https://item.lenovo.com.cn/product/1024603.html)

- **像素数决定一帧有多大。** 1080p（1920×1080）约 207 万像素，1440p（2560×1440）约 369 万，4K（3840×2160）约 829 万。原生 4K 每帧的像素数是 1080p 的四倍，实际帧率还受游戏、画质和硬件限制。
- **Hz 表示屏幕每秒能刷新几次，FPS 表示游戏每秒生成几帧。** 144 Hz 屏幕每隔约 6.94 毫秒刷新一次。想每次刷新都有新画面，要看电脑在目标游戏、分辨率和画质下能否持续按这个节奏出帧。[Intel 刷新率说明](https://www.intel.com/content/www/us/en/gaming/resources/highest-refresh-rate-gaming.html)

## 电竞显示器的其余参数

| 标注 | 实际含义 |
| --- | --- |
| 1000R | 屏幕曲面对应半径 1000 毫米的圆弧。半径越小，弯曲越明显。 |
| 1 ms MPRT | 描述运动画面的模糊程度。三星 C27G55TQWC 的 1 ms 来自 Extreme 模式，按键到画面的总延迟需要单独测量。 |
| FreeSync Premium | 在支持的范围内让屏幕刷新跟随显卡出帧，减少画面撕裂。 |
| HDR10 | 屏幕能接收 HDR10 信号。判断高光是否够亮、暗部能否保留细节，还需看峰值亮度、黑位或 DisplayHDR 认证等级。 |
| 100% sRGB | 表示对 sRGB 色域的覆盖范围。修图还要看色准，即同一种颜色实际显示出来偏差多大。 |
