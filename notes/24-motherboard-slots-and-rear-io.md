# P24 · 22-2.总结主板的知识点｜看主板布局图，分清后置接口与扩展接针

查主板时，先记下完整型号，再到商品页的「商品介绍」找主板布局图和后置接口图。布局图用来找装机位置，后置接口图用来找机箱背面能插的设备。看中某个接口后，再用对应型号的官方手册核对协议和速率。

## 在布局图上找四种装机位置

以华硕 ROG STRIX Z690-A GAMING WIFI **D4**「吹雪」为例，商品页的 D4 和 D5 是不同型号。下列编号对应 D4 的主板布局图。[华硕官方图解](https://rog.asus.com.cn/motherboards/rog-strix/rog-strix-z690-a-gaming-wifi-d4-model/)

| 要装的部件 | 图上看哪里 | 装之前核对什么 |
| --- | --- | --- |
| CPU | ① LGA1700 插槽 | 用完整 CPU 型号查这块板的支持列表和所需 BIOS 版本。 |
| 内存 | ④ CPU 右侧的四条 DDR4 DIMM 槽 | D4 版使用 DDR4。图上带 OC 的频率是超频规格。 |
| 显卡 | ② 最靠近 CPU 的 PCIe 长槽 | 首条支持 PCIe 5.0 ×16。下面另一条长槽只有 PCIe 3.0 ×4 的电气带宽，两槽外形相近。 |
| M.2 固态硬盘 | ⑤ 四个 M.2 位置 | 四个都支持 PCIe 4.0 ×4。如果手里的盘是 SATA 协议的 M.2，只有 M.2_4 支持。 |

## 从外设反查接口

- **显示器**　看后置面板有没有与显示器匹配的 HDMI 或 DisplayPort（DP）。用 CPU 核显输出时，接主板后置视频口，并确认该 CPU 有核显。用独立显卡输出时，接显卡自己的视频口。
- **网线和耳麦**　华硕后置接口图的 ⑧ 是 2.5 GbE 有线网口，⑫ 是音频插孔。插耳机或麦克风时，按手册区分音频输出和麦克风输入。
- **USB-C 和雷电外设**　同一张图里，⑦ 是后置 USB 3.2 Gen 2×2 Type-C，标称 20 Gb/s。音频孔旁的 ⑪ 也是后置 USB-C，标称 10 Gb/s。⑬ 在板内，用来接机箱前置 USB-C。⑯ 也在板内，要配合另购的兼容雷电扩展卡使用。手里的外设若要求雷电，要查主机是否已提供相应的雷电端口。上述速率均为接口规格。[华硕中文手册](https://dlcdnets.asus.com/pub/ASUS/mb/LGA1700/ROG_STRIX_Z690-A_GAMING_WIFI_D4/C19937_ROG_STRIX_Z690-A_GAMING_WIFI_D4_UM_V6_WEB.pdf)
- **换型号就重查图例**　技嘉 Z690 AORUS MASTER「超级雕」用 DDR5。后置面板有五个红色 USB-A，技嘉将它们列为 USB 3.2 Gen 2，标称 10 Gb/s。其他型号的同色插口要查各自规格。选笔记本时，同样按整机的具体型号核对接口和可扩展部件。[技嘉官方规格](https://www.gigabyte.com/Motherboard/Z690-AORUS-MASTER-rev-1x/sp)
