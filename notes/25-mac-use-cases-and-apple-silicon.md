# P25 · 23.苹果电脑的用途与硬件的未来｜按用途选 Mac，读懂 M1 系列性能图和屏幕规格

## 按软件和工作地点选机型

- 经常移动办公，MacBook Air 和 MacBook Pro 自带屏幕和电池。固定工位若已有显示器，可接 Mac mini 或 Mac Studio。iMac 自带显示屏，Studio Display 本身是显示器。
- 必用的 Windows 软件要逐项查应用、插件和外设驱动。M1 Mac 可通过 Parallels Desktop 虚拟运行 Windows 11 Arm 专业版或企业版，需相应 Windows 许可证。Apple 的“启动转换助理”适用于受支持的 Intel Mac。[微软的 Windows 11 运行说明](https://support.microsoft.com/zh-cn/windows/experience/platform-variants/options-for-using-windows-11-with-mac-computers-with-apple-m1-m2-and-m3-chips) · [Apple 启动转换说明](https://support.apple.com/zh-cn/102622)

## 用自己的任务读 M1 性能图

M1 系列把 CPU、GPU 等集成在系统级芯片（SoC）里，两者共享统一内存。选配置时同时看 CPU 核数、GPU 核数和共享内存总容量。M1 Ultra 以两枚 M1 Max 晶粒互连，能快多少仍取决于软件和任务。[M1 Ultra 架构](https://www.apple.com.cn/newsroom/2022/03/apple-unveils-m1-ultra-the-worlds-most-powerful-chip-for-a-personal-computer/)

视频中的 Apple 测试图列出 **2021 款 14 英寸 MacBook Pro** 在指定任务上的最高加速倍率，基准机是 13 英寸四核 Core i7／Iris Plus。两款新机都是 10 核 CPU，GPU 分别为 16 核和 32 核。[Apple 对照机配置，脚注 3、4](https://www.apple.com.cn/newsroom/2021/10/apple-unveils-game-changing-macbook-pro/)

| 任务 | M1 Pro | M1 Max |
| --- | ---: | ---: |
| Xcode 构建项目 | 3.7 倍 | 3.7 倍 |
| Photoshop 的 GPU 加速滤镜和功能 | 3.3 倍 | 3.5 倍 |
| Final Cut Pro 渲染 4K 项目 | 9.2 倍 | 13.4 倍 |

同样从 M1 Pro 换成 M1 Max，4K 渲染的表现拉开了差距，Xcode 构建的最高倍率相同。图里的 16 英寸机型另测 8K 渲染，旧机也换成 Radeon Pro 5600M，跨图相除无法得出两款新机的速度差。

## 从 2021 款规格表找答案

| 想确认什么 | 看哪项指标 |
| --- | --- |
| 屏幕适不适合 HDR 与高刷新率 | 14 英寸款实际为 14.2 英寸、3024×1964、254 ppi。SDR 亮度 500 尼特，HDR 全屏持续 1000 尼特，峰值 1600 尼特。ProMotion 最高 120 Hz，可在“系统设置 → 显示器 → 刷新率”查看。 |
| 离开电源能用多久 | 影片播放／无线上网是两种负载。14 英寸款最长 17／11 小时，16 英寸款最长 21／14 小时。估算剪辑续航需找剪辑负载的实测。 |
| 外设要不要转接 | 三个雷雳 4 端口采用 USB-C 接头，兼容 USB 4，最高 40 Gb/s。机身另有 HDMI、SDXC 卡槽和 MagSafe 3 充电口。 |
