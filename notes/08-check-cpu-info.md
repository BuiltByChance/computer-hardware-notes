# P8 · 7.查看电脑的CPU信息｜用 Windows 和 CPU-Z 查型号、看频率与读跑分

只查完整型号、核心数或实时利用率，用 Windows 自带工具就够了。想看处理器代号、缓存和单线程／多线程跑分，再打开 CPU-Z。

## 用 Windows 确认型号、核心数和系统类型（00:00、05:17）

| 想查什么 | 从哪里打开 | 怎么读 |
| --- | --- | --- |
| CPU 或显卡型号 | 右键「开始」→「设备管理器」→ 展开「处理器」或「显示适配器」 | 抄下完整型号和末尾字母。讲师电脑列了 16 行同名 i9-9900KF，每行对应一个逻辑处理器。 |
| 系统位数和内存容量 | 右键「此电脑」→「属性」，或打开「设置 → 系统 → 关于」 | 在「设备规格」看「系统类型」和「机带 RAM」。课中显示 64 位操作系统、基于 x64 的处理器、32.0 GB RAM，下载工具时用的是 x64 版。 |
| 物理核心数、逻辑处理器数和当前负载 | 按 `Ctrl + Shift + Esc` →「性能」→「CPU」。Windows 10 若只列出应用，先点「详细信息」 | 在图表下方分别看「内核」和「逻辑处理器」。示例为 8 核、16 个逻辑处理器。右键曲线，选「将图形更改为 → 逻辑处理器」，会出现 16 张小图。选「总体利用率」可切回一张总图。 |

「速度」和「利用率」会刷新。课中同一台机器的基本速度是 3.60 GHz，任务管理器一度显示 4.68 GHz、约 16% 利用率。读数高于基本频率可以来自自动睿频，单凭这个画面无法判断是否做过手动超频。[微软的核心数与逻辑处理器查看方法](https://support.microsoft.com/zh-cn/windows/experience/compatibility/find-out-how-many-cores-a-processor-on-a-windows-device-has) · [英特尔 i9-9900KF 规格](https://www.intel.cn/content/www/cn/zh/products/sku/190887/intel-core-i99900kf-processor-16m-cache-up-to-5-00-ghz/specifications.html)

## 下载并读懂 CPU-Z（02:08–03:45）

1. 打开 CPUID 的 CPU-Z 产品页，找到 Windows x86/x64 的「ZIP • Chinese」，进入后点「Download Now」。视频使用 2.00.0 x64。2026-11-19 核对时官网列出的版本为 3.02，仍提供免费中文 ZIP 版。[CPU-Z 官方下载入口](https://www.cpuid.com/softwares/cpu-z.html)
2. 把 ZIP 解压到一个单独的文件夹。在「系统类型」为 x64 的 64 位 Windows 上，打开 `cpuz_x64.exe`。32 位 x86 Windows 对应同一压缩包里的 `cpuz_x32.exe`。看到「处理器」页显示本机型号即已启动成功。
3. 先读固定规格，再读动态值。讲师的 i9-9900KF 在「处理器」页显示代号 Coffee Lake、8 核 16 线程、三级缓存 16 MB、TDP 95 W。「规格」一行的 `@ 3.60GHz` 是基本频率，「时钟（核心 #0）」一栏显示的是采样时的核心速度，截图里约为 4697 MHz。95 W 是热设计功耗规格，实时用电量需要另行测量。[英特尔 i9-9900KF 规格](https://www.intel.cn/content/www/cn/zh/products/sku/190887/intel-core-i99900kf-processor-16m-cache-up-to-5-00-ghz/specifications.html)

## 跑一次基准，并读对两组数字（03:45–05:19）

1. 打开「测试分数」（Bench），在下方「参考」选择要对照的 CPU。「这个处理器」对应运行 CPU-Z 的本机，「参考」对应软件内置的对照成绩。
2. 点击「测试处理器分数」（Bench CPU）。等待运行中的「停止」变回测试按钮，再记录单线程、多线程两栏的最终分数。比较时记下基准版本和使用的线程数。课中两轮都是基准 **17.01.64**，本机用 **16 个线程**。
3. 按相同指标横向比较。下面是讲师电脑的两次实测，复测同一颗 CPU 也会有小幅波动。

| 选择的参考处理器 | 本机 i9-9900KF 单线程 | 参考单线程 | 本机 i9-9900KF 多线程 | 参考多线程 |
| --- | ---: | ---: | ---: | ---: |
| Core i9-12900K | 534.1 | 831 | 5040.0 | 11440 |
| Ryzen 9 5950X | 525.7 | 648 | 5027.2 | 11906 |

第二轮勾选多线程栏的「参考」后，5950X 的参考分显示为 100%，本机显示约 **42%**，即 5027.2 ÷ 11906。这个百分比回答“本机跑了参考分的几成”。要看“此刻 CPU 有多忙”，读任务管理器的「利用率」。这些分数衡量 CPU-Z 的测试负载，游戏帧率或应用耗时需要对应的测试。
