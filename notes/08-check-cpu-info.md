# P8 · 7.查看电脑的CPU信息｜用 Windows 和 CPU-Z 查型号、看频率与读跑分

## 在 Windows 查型号、核心数与负载

| 想查什么 | 入口 | 怎样判断 |
| --- | --- | --- |
| CPU、显卡型号 | 右键「开始」→「设备管理器」→「处理器」或「显示适配器」 | 记录完整型号及后缀。i9-9900KF 在「处理器」下有 16 个同名条目，对应 16 个逻辑处理器。 |
| 系统位数、已装内存 | 右键「此电脑」→「属性」，或「设置 → 系统 → 关于」 | 在「设备规格」看「系统类型」和「机带 RAM」，按系统位数选择工具版本。 |
| 物理核心、逻辑处理器、当前负载 | `Ctrl + Shift + Esc` →「性能 → CPU」 | 示例为 8 核、16 个逻辑处理器。右键曲线 →「将图形更改为 → 逻辑处理器」可分开观察 16 张图。 |

任务管理器的「速度」随负载变化。i9-9900KF 基本频率为 3.60 GHz，采样时达到 4.68 GHz，自动睿频也能产生这样的读数。[英特尔处理器规格](https://www.intel.cn/content/www/cn/zh/products/sku/190887/intel-core-i99900kf-processor-16m-cache-up-to-5-00-ghz/specifications.html)

## 用 CPU-Z 查规格、读跑分

1. 在 CPUID 的 Windows x86/x64 下载区选「ZIP • Chinese」→「Download Now」，解压。在 x64 系统运行 `cpuz_x64.exe`，32 位 x86 系统运行 `cpuz_x32.exe`。[CPU-Z 官方下载](https://www.cpuid.com/softwares/cpu-z.html)
2. 「处理器」页给出代号、核心、线程、缓存与热设计功耗。例如 Coffee Lake、8 核 16 线程、三级缓存 16 MB、TDP 95 W。「核心速度」是实时采样值，TDP 是散热设计规格。
3. 在「测试分数」（Bench）选参考处理器，点「测试处理器分数」。等「停止」变回测试按钮，再读本机和参考的单线程、多线程分数。比较同一颗 CPU 的多次测试时，保持基准版本与线程设置一致。

例如基准 **17.01.64**、16 线程下，本机 i9-9900KF 单线程 **525.7**、多线程 **5027.2**，软件内置的 Ryzen 9 5950X 参考值分别为 **648、11906**。多线程的 **42%** 来自 5027.2 ÷ 11906，表示相对成绩。要看当时的 CPU 利用率，读任务管理器。
